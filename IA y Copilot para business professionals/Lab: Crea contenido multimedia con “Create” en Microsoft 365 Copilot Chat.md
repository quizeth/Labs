### Lab: Crea contenido multimedia con “Create” en Microsoft 365 Copilot Chat

#### Introducción

Imagina que trabajas en una consultora tecnológica y necesitas generar rápidamente contenido visual y narrativo para campañas internas y clientes.

Usarás **Create** para diseñar imágenes, vídeos, historias y materiales visuales listos para usar.

En este ejercicio aprenderás a:
- Crear y editar imágenes con prompts avanzados
- Generar contenido visual (posters, banners, infografías)
- Crear historias y guiones
- Diseñar activos reutilizables

**Duración estimada:** 25–30 minutos  
**Nota:** Usa Copilot en modo web (https://m365.cloud.microsoft/create)

---

#### Tarea 1: Crear una imagen profesional

##### Contexto
Create permite generar imágenes listas para uso corporativo.

##### Tarea práctica
- Abre Create
- Prompt:
Crea una imagen corporativa sobre transformación digital en logística, estilo moderno, colores azul y blanco, con elementos de datos y automatización.

- Prompt avanzado:
Genera una imagen en estilo corporativo minimalista, con fondo limpio, iluminación suave, iconografía de analítica de datos y transporte, composición centrada, formato horizontal para presentación ejecutiva.

- Ajusta variaciones (estilo, color, composición)

---

#### Tarea 2: Editar la imagen generada

##### Contexto
Puedes iterar sobre imágenes sin empezar de cero.

##### Tarea práctica
- Prompt:
Haz la imagen más dinámica añadiendo personas interactuando con dashboards digitales.

- Prompt avanzado:
Mejora la profundidad visual, añade contraste, incluye elementos en primer plano y aplica un estilo semi-realista manteniendo coherencia corporativa.

---

#### Tarea 3: Diseñar un póster

##### Contexto
Create permite generar materiales promocionales.

##### Tarea práctica
- Prompt:
Diseña un póster para un evento de innovación en logística con título, fecha y mensaje principal.

- Prompt avanzado:
Diseña un póster vertical estilo corporativo moderno, con jerarquía visual clara, tipografía sans-serif, colores coherentes con branding tecnológico, espacio para título, subtítulo y call-to-action.

---

#### Tarea 4: Crear un banner

##### Contexto
Los banners se usan en web o campañas internas.

##### Tarea práctica
- Prompt:
Crea un banner horizontal para lanzar un servicio de analítica de datos.

- Prompt avanzado:
Crea un banner horizontal 16:9, con enfoque en mensaje principal, contraste alto, iconos simples de datos y automatización, espacio para CTA, optimizado para web corporativa.

---

#### Tarea 5: Diseñar una infografía

##### Contexto
Las infografías ayudan a resumir información compleja.

##### Tarea práctica
- Prompt:
Crea una infografía sobre los beneficios de la analítica de datos en logística.

- Prompt avanzado:
Diseña una infografía clara y visual con 4 secciones: eficiencia, reducción de costes, visibilidad y toma de decisiones. Usa iconos simples, colores consistentes y estructura vertical fácil de leer.

---

#### Tarea 6: Crear una historia (storytelling)

##### Contexto
Create puede generar narrativas para presentaciones o contenido.

##### Tarea práctica
- Prompt:
Crea una historia breve sobre cómo una empresa logística mejora usando IA.

- Prompt avanzado:
Escribe una historia de cliente en tono profesional, con estructura: problema, solución, impacto. Incluye métricas y lenguaje orientado a negocio.

---

#### Tarea 7: Crear un guion de video

##### Contexto
Create puede ayudarte a idear contenido audiovisual.

##### Tarea práctica
- Prompt:
Crea un guion corto para un video promocional del servicio.

- Prompt avanzado:
Genera un guion de video de 60 segundos con estructura: apertura impactante, problema, solución, beneficios y cierre con llamada a la acción. Incluye सुझाव visuales por escena.

---

#### Tarea 8: Iteración multi-formato

##### Contexto
Reutilizar contenido es clave.

##### Tarea práctica
- Prompt:
Convierte este contenido en:
1. Imagen promocional  
2. Banner  
3. Mensaje corto para redes  

---

#### Tarea opcional de cierre: Reflexión

Prompt:
Crea una lista de cómo puedo usar Create para generar contenido visual en mi día a día profesional.

---

#### Resumen

| Concepto | Punto clave |
|----------|------------|
| Imágenes | Crear y editar rápidamente |
| Visuales | Posters, banners, infografías |
| Storytelling | Narrativas profesionales |
| Video | Guiones listos para producción |
| Iteración | Refinar sin rehacer |

---

#### Buenas prácticas

- Empieza simple, luego refina con prompts avanzados  
- Define estilo visual desde el inicio  
- Usa formatos reutilizables  
- Ajusta según audiencia
