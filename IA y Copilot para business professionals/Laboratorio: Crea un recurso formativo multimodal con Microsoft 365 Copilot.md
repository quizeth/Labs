# Laboratorio: Crea un recurso formativo multimodal con Microsoft 365 Copilot

## Resumen

En este laboratorio crearás un pequeño recurso formativo multimodal sobre un tema profesional usando **Microsoft 365 Copilot**. El flujo incluye **generación de imagen**, **edición de imagen**, **creación de vídeo**, **generación de audio a partir de un archivo** y **exploración de otros formatos visuales** disponibles en **Create** y **Copilot Library**, como **infografías**, **stories**, **posters** y **banners**. 

**Duración estimada:** 25–30 minutos

---

## Escenario

Formas parte del equipo de formación interna de una organización. Tu equipo necesita preparar una **microlección profesional** sobre uno de estos temas:

- Buen uso de la IA en el trabajo
- Detección de phishing
- Productividad con Copilot
- Trabajo híbrido y colaboración

Tu objetivo es producir, en una sola sesión, un pequeño paquete multimodal compuesto por:

- una imagen,
- una versión editada de esa imagen,
- un vídeo breve,
- un recurso de audio,
- y una pieza visual adicional.

Esta actividad te permitirá practicar cómo Copilot trabaja más allá del texto.

---

## Requisitos previos

Antes de comenzar, asegúrate de contar con lo siguiente:

- Acceso a **Microsoft 365 Copilot**.
- Acceso a **Copilot Chat**.
- Acceso a **Create** dentro de la experiencia de Microsoft 365 Copilot.
- Acceso a **OneDrive para trabajo o escuela**.
- Un archivo en **Word**, **PDF** o una **grabación de Teams** para la parte de audio.
- Si el entorno lo permite, acceso a la creación y edición de vídeo.

> [!NOTE]
> Algunas funciones pueden variar según la configuración del tenant, el tipo de licencia o las opciones habilitadas por el administrador.

# Tarea 1: Generar una imagen en Copilot Chat

## Objetivo

Crear y refinar una imagen para acompañar una microlección profesional.

## Pasos

1. Abre **Microsoft 365 Copilot Chat**.
2. En el cuadro de mensaje, escribe un prompt como el siguiente:

```text
Crea una imagen para una microlección corporativa sobre uso responsable de la IA en el trabajo.
Debe mostrar un entorno profesional moderno, personas colaborando con documentos digitales, y una estética limpia y confiable.
Usa tonos azul, violeta y blanco.
Formato horizontal.
```

3. Envía el prompt y espera a que Copilot genere la imagen.
4. Revisa el resultado y decide si comunica bien el mensaje.

### Prompt alternativo

```text
Crea una ilustración profesional para formación interna sobre cómo detectar intentos de phishing.
Debe incluir a una persona revisando un correo sospechoso en su equipo y señales visuales de alerta y seguridad.
Estilo limpio, corporativo y fácil de entender.
```

3. Selecciona la imagen generada para abrir el panel de edición.
4. Realiza una o dos mejoras visuales, por ejemplo:
   - añadir texto,
   - recortar,
   - ajustar el encuadre,
   - simplificar el diseño.
5. Si tu entorno lo permite, abre la imagen en una experiencia de edición más amplia.
6. Guarda o copia el resultado final.

### Sugerencia de refinamiento

```text
Haz esta imagen más adecuada para formación corporativa.
Reduce elementos decorativos, mejora la claridad visual y deja espacio para añadir un titular en la parte superior.
```

## Resultado esperado

Una imagen mejorada y más adecuada para un contexto educativo o corporativo.

# Tarea 2: Crear un vídeo en Create

## Objetivo

Crear un vídeo breve que resuma tu microlección.

## Pasos

1. Abre la app de **Microsoft 365 Copilot**.
2. En el panel izquierdo, selecciona **Create**.
3. Selecciona **Create a video**.
4. Escribe un prompt como el siguiente:

```text
Crea un vídeo breve para formación interna sobre cómo detectar mensajes de phishing.
Incluye consejos para revisar el remitente, desconfiar de enlaces inesperados y evitar adjuntos sospechosos.
Usa un tono profesional, claro y apto para personal de oficina.
```

5. Si quieres, añade un archivo o una presentación para orientar mejor el contenido del vídeo.
6. Selecciona **Create** y revisa el borrador generado.
7. Si el entorno lo permite, realiza pequeños ajustes con las herramientas disponibles.
8. Si dispones de edición avanzada, abre el vídeo en el editor correspondiente.

> [!TIP]
> Si no ves la opción **Create a video**, documenta esta limitación y continúa con el resto del laboratorio.

## Resultado esperado

Un vídeo breve que sirva como introducción o resumen audiovisual de la microlección.

# Tarea 3: Generar audio a partir de un archivo en OneDrive

## Objetivo

Crear un recurso de audio resumido a partir de un archivo compatible.

## Pasos

1. Abre **OneDrive** en la web e inicia sesión con tu cuenta de trabajo o escuela.
2. Selecciona un archivo compatible, por ejemplo:
   - un documento de Word,
   - un PDF,
   - o una grabación de Teams.
3. Abre el asistente de Copilot en la página de OneDrive.
4. Selecciona la opción para crear un **audio overview** del archivo.
5. Espera a que Copilot genere el audio.
6. Reproduce el audio y revisa el resultado.
7. Si aparece la opción, prueba también:
   - pausar y reanudar,
   - cambiar la velocidad,
   - revisar la transcripción,
   - guardar el audio.

> [!IMPORTANT]
> Si la función de audio no aparece o no funciona con tu archivo, documenta la limitación y continúa con la siguiente tarea.

## Resultado esperado

Un audio breve que resuma el contenido del archivo seleccionado.

# Tarea 4: Explorar otros contenidos no textuales en Create y Copilot Library

## Objetivo

Explorar otros formatos visuales que Copilot puede generar.

### Opción A: Crear una infografía

1. En la app de **Microsoft 365 Copilot**, abre **Create**.
2. Selecciona **Design an infographic**.
3. Escribe un prompt como este:

```text
Diseña una infografía para empleados sobre buenas prácticas al usar IA en el trabajo.
Incluye tres secciones: verificación de contenido, protección de datos y revisión humana.
Estilo moderno, corporativo y fácil de leer.
Formato vertical.
```

4. Si quieres, añade un archivo que sirva como base.
5. Genera la infografía y revisa el resultado.
6. Si lo deseas, ábrela en el editor para hacer ajustes.

### Opción B: Diseñar un banner

1. En **Create**, selecciona **Design a banner**.
2. Escribe un prompt como este:

```text
Diseña un banner para un curso interno titulado “IA y Copilot para profesionales”.
Debe ser moderno, limpio y corporativo.
Usa un fondo claro con acentos azul y violeta.
```

3. Revisa las opciones generadas.
4. Si lo deseas, abre el editor y realiza ajustes.

### Revisar el contenido en Copilot Library

1. En **Microsoft 365 Copilot**, abre **Copilot Library**.
2. Revisa los visuales generados durante el laboratorio.
3. Identifica qué tipos de contenido aparecen disponibles en tu entorno.
4. Selecciona uno y valora si sería útil para formación, comunicación interna o presentaciones.

## Resultado esperado

Un recurso visual adicional y una visión más amplia de los formatos no textuales disponibles en Copilot.
