# Lab 3: Crea contenido multimedia con “Create” en Microsoft 365 Copilot Chat

Trabajas como consultor en una empresa tecnológica que está acelerando el uso de herramientas de IA generativa en proyectos internos. En las últimas semanas, varios equipos han empezado a utilizar Copilot sin directrices claras, lo que ha generado dudas sobre el uso de datos sensibles, la calidad de los contenidos generados y posibles sesgos.

El equipo de dirección te encarga diseñar una **micro‑campaña interna de concienciación** dirigida a empleados no técnicos. El objetivo es explicar de forma clara qué es la IA responsable y cómo aplicarla en el día a día.
La campaña debe ser:

Visual, breve y fácil de entender
Reutilizable en distintos canales (email, intranet, presentaciones)
Creada únicamente con Microsoft 365 Copilot (licencia básica)



En este ejercicio aprenderás a usar **Create**:
- Crear y editar imágenes con prompts avanzados
- Generar contenido visual (posters, banners, infografías)
- Crear historias y guiones
- Diseñar activos reutilizables

**Duración estimada:** 30 minutos  

> [!NOTE]
> **Nota:** Para completar este laboratorio necesitas una suscripción a Microsoft 365. Estas tareas están diseñadas específicamente para usarse en **modo web** en Microsoft 365 Copilot Chat. Si tienes una licencia de Microsoft 365 Copilot, asegúrate de **cambiar manualmente al modo web** cuando abras Copilot Chat, ya que podría estar en modo trabajo por defecto. Usar el **modo web** garantiza que los prompts funcionen como se espera y obtengan información de contenido web público.

---
### Cómo acceder a Create
Create no aparece siempre como un botón único. Puedes llegar a él de varias formas:

#### Desde Copilot Chat (web o Teams)
Escribe un prompt que incluya:“crea”, “genera”, “diseña”, “imagen”, “póster”
Copilot activa automáticamente Create.

#### Desde botón “Create” (si aparece en tu tenant o interfaz)
Accede a https://m365.cloud.microsoft/create
Selecciona tipo: imagen, visual, historia, etc.

#### Desde Microsoft Designer (integrado)
Se abre automáticamente al pedir diseños visuales más avanzados. También se puede añadir explícitamente a cualquier prompt como si fuera un documento o agente (icono de + en el cuadro de prompts).

En todos los casos, la clave es el **prompt estructurado** (contexto + formato + estilo).

---

### Tarea 1: Definir el mensaje clave

Abre un nuevo chat en M365 Copilot y escribe el siguiente prompt:
````
Actúa como experto en comunicación interna. Explica IA responsable para empleados no técnicos. Incluye riesgos y buenas prácticas.
````
Refina el prompt:
````
Reduce a 3 mensajes claros y accionables.
````

---

### Tarea 2: Genera y edita una imagen

Puedes iterar sobre imágenes sin empezar de cero. En Create (chat o create.microsoft), define explícitamente la imagen que vayas a crear:

````
Crea una imagen:
- contenido: empleados en oficina usando IA de forma responsable
- estilo: corporativo, minimalista
- colores: azul y blanco
- formato: cuadrado
- emoción: confianza y seguridad````
````
Itera:
````
Haz la imagen más simple y con menos elementos.
````
Para editar la imagen mediante **prompts**, no necesitas salir del chat ni abrir otra herramienta.
**Ventajas:**
- Iteración rápida
- No requiere herramientas manuales
- Ideal para ajustes conceptuales
````
Añade un icono visual que represente protección de datos.
````
````
Cambia el estilo a ilustración plana (flat design).
````
````
Haz la imagen más moderna y con mayor contraste.
````

Cuando quieres más control visual, puedes editar la imagen manualmente con **Microsoft Designer**.

1. Selecciona la imagen para abrirla en Designer.
   
3. Explora opciones guiadas como:
  - Layout (Diseño): mover elementos, cambiar composición
  - Style (Estilo): cambiar look visual completo
  - Color: aplicar paletas automáticas
  - Text: añadir títulos o mensajes
  - Resize (Formato): cuadrado, vertical, banner
    
3. Ajusta tu imagen en Designer.
  - Cambia el tamaño:
    - cuadrado → redes/intranet
    - vertical → póster
  - Ajusta la marca y color:
    - escoge una paleta de colores diferente o una marca
  - Añade texto corto:
    - ejemplo: ````Usa la IA de forma responsable````

### Tarea 3: Diseñar un póster

Vuelve al chat y escribe el siguiente prompt:

- Prompt:
````
Diseña un póster:
- contenido: campaña sobre uso responsable de IA
- título: claro y atractivo
- incluye: 3 reglas (haz / evita)
- estilo: infografía sencilla
- colores: azul/blanco
- formato: vertical
````
- Itera:
````
Reduce texto y prioriza elementos visuales.
````
---

### Tarea 4: Crear una historia (storytelling)

Aquí, Create usa un formato narrativo.

- Prompt:
````
Crea una historia:
- contenido: empleado usa IA mal y luego corrige
- tono: cercano
- longitud: 120 palabras
````
- Itera:
````
Añade una moraleja final en una frase.
````
---

### Tarea 5: Crear un guión de vídeo

Define el resultado como pieza audiovisual clara y reutilizable. Cuanto más estructurado sea el prompt, mejor calidad tendrá el guion. Incluye siempre:

- Duración (ej. 30s)
- Formato (escenas)
- Canal (comunicación interna)
- Objetivo (concienciar)

- Prompt:
````
Crea un guion de vídeo:
- duración: 30 segundos
- formato: escenas cortas
- público: empleados no técnicos
- objetivo: explicar uso responsable de IA
- incluye: texto en pantalla y mensaje final claro
````
- Itera:
````
Añade:
- 3 escenas (problema, cambio, solución)
- tono cercano
- cierre con llamada a la acción

Haz el lenguaje más simple y directo. Reduce a mensajes clave fáciles de recordar.
````
---

### Tarea 6: Reutiliza el contenido

Aquí entrenas una de las capacidades clave de Create: transformar contenido en múltiples formatos.

- Prompt para convertirlo en un email:
````
Convierte el contenido en un email interno:
- tono: cercano y profesional
- longitud: breve
- incluye: mensaje clave + 3 recomendaciones
````
- Itera:
````
Hazlo más directo y fácil de leer en móvil.
````

- Prompt para convertirlo en una presentación de PowerPoint de una slide:
````
Resume el contenido en una slide:
- título claro
- máximo 3 bullets
- enfoque visual
````
- Itera:
````
Hazlo más visual y reduce texto.
````

- Otras sugerencias:
````
Convierte el contenido en mensajes para intranet.
````
````
Resume el contenido en una checklist práctica.
````
---
### Tarea 7: Compilación final en Pages
- Ve a cada conversación o elemento generado y añade la imagen, póster, historia, guión, etc. a una **nueva página**.
- Después:
````
Organiza este contenido como documento de campaña interna.
````
- Refina:
````
Añade título, secciones claras y resumen ejecutivo.
````
- (Opcional) Añade más elementos y reestructura la página acorde a tus gustos.

### Resumen

| Área | Qué se hace | Punto clave | Ejemplo |
|------|------------|-------------|---------|
| Mensaje | Definir ideas principales | Mantenerlo simple y claro | “Reduce a 3 ideas claras” |
| Imagen | Crear y mejorar una imagen | Indicar qué aparece, estilo, colores y formato | “Imagen de oficina, estilo simple, colores azul/blanco, cuadrada” |
| Edición imagen | Ajustar la imagen | Usar cambios con texto o herramientas visuales | “Hazla más simple” o cambiar colores en Designer |
| Póster | Crear un diseño visual | Título + pocas reglas claras | “Póster con 3 reglas fáciles” |
| Historia | Explicar con un ejemplo | Mostrar error y solución | “Historia con aprendizaje final” |
| Vídeo | Crear guion corto | Dividir en escenas simples | “Guion de 30 segundos en 3 partes” |
| Reutilizar | Adaptar contenido | Usar el mismo mensaje en varios formatos | “Convierte en email o slide” |
| Pages | Unir todo | Ordenar en un documento final | “Organiza como documento completo” |

#### Buenas prácticas

- Empieza simple, luego refina con prompts avanzados  
- Define estilo visual desde el inicio  
- Usa formatos reutilizables  
- Ajusta según audiencia

#### Errores comunes al crear y editar elementos visuales con Copilot

| Error | Qué pasa | Cómo evitarlo |
|------|---------|--------------|
| Prompt poco claro | La imagen sale genérica o no útil | Especifica qué aparece, estilo, colores y formato |
| Falta de contexto | No representa el caso real | Añade contexto: oficina, empleados, uso de IA |
| Demasiados detalles | Imagen sobrecargada | Empieza simple y añade mejoras después |
| No indicar estilo | Resultado incoherente | Define siempre el tipo visual (simple, foto, dibujo) |
| Ignorar colores | No encaja con la imagen de la empresa | Define colores desde el inicio |
| No mejorar la primera versión | Resultado poco cuidado | Crea varias versiones y ajusta |
| Cambiar todo a la vez | No sabes qué mejora | Cambia solo una cosa cada vez |
| No usar referencia previa | Se pierde coherencia | Usa “basado en la imagen anterior” |
| No usar herramientas visuales | Imagen poco pulida | Ajusta diseño, colores y formato manualmente |
| Demasiado texto en la imagen | Difícil de leer | Mantén textos cortos y claros |
| Formato incorrecto | No sirve para el uso final | Define si es cuadrado, vertical o horizontal |
