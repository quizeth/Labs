# 📚 Labs – Materiales de cursos

Este repositorio reúne materiales prácticos para distintos cursos.  
Cada curso está organizado en su propia carpeta e incluye laboratorios con instrucciones detalladas.

---

## 🎯 Objetivo

El objetivo de este repositorio es servir como apoyo práctico a los cursos, permitiendo:

- Seguir actividades guiadas paso a paso  
- Aplicar los conceptos explicados en clase  
- Aprender de forma práctica
---

## 📂 Estructura del repositorio

- Cada carpeta corresponde a un curso  
- Dentro de cada curso se incluyen:

  - **Laboratorios** que incluyen instrucciones detalladas para guiar la realización de la práctica paso a paso
  - **Archivos** de apoyo, si son necesarios  

---

## 🧭 Cómo utilizar este repositorio

No es necesario tener conocimientos de Git ni disponer de una cuenta en GitHub.

Pasos:

1. Accede al repositorio desde el navegador  
2. Entra en la carpeta del curso correspondiente  
3. Selecciona el laboratorio que se va a realizar  
4. Lee las instrucciones completas  
5. Sigue los pasos en orden  
6. Descarga los archivos si el laboratorio lo requiere  

---

## ✅ Recomendaciones

- Lee todo el laboratorio antes de empezar  
- Sigue los pasos en el orden indicado  
- Avanza a tu ritmo  
- Asegúrate de entender cada paso antes de continuar  

---

## ❓ Preguntas frecuentes (FAQ)

**¿Necesito tener cuenta en GitHub?**  
No. Puedes acceder a todos los materiales directamente desde el navegador.

**¿Tengo que descargar el repositorio completo?**  
No es necesario. Solo descarga los archivos indicados en cada laboratorio.

**¿Qué hago si no entiendo un paso?**  
Revisa las instrucciones y vuelve a intentar el proceso. Si sigue sin quedar claro, consulta con la docente.

**¿Qué hago si algo no funciona?**  
Revisa los pasos, recarga la página o prueba con otro navegador. Si persiste, anota el error y compártelo.
